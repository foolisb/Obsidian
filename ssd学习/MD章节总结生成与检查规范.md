# MD 章节总结生成与检查规范

> 适用范围：`ssd学习/` 下的章节总结 Markdown（含原书裁图 + 概念示意图）。每次生成/修改后按“检查清单”自检后再交付。

## 一、图片规则

- **原书图**：从原书 PDF 裁切**局部图**，保持“不带原书图注、不带整页、不夹正文”；命名统一 `fig_0X_YY-pZZZ.png`，放 `第N章_插图/`。
- **概念图**：自绘示意图，命名 `concept_<主题>.png`；图中不要出现“原书图注”；需明显标注“概念示意图，非原书插图”。
- **引用方式**：MD 中用相对路径 `第N章_插图/xxx.png`，不要用绝对路径/网络链接。
- **完整性**：生成后用 `audit_crop_margins.py` 检查原图边缘是否被切；整跨页图贴边属正常，但不应缺内容。

## 二、图注（下标）规则

- 每张图下一行紧跟一条图注：`**图N-K 标题（说明）**`。
- **编号必须连续**：从 `图N-1` 开始按文档顺序递增，不看原书图号；原书图号放括号里：`（原书图N-M · 局部截图）`。
- **概念图纳入同一编号序列**：`**图N-K 标题（概念示意图，非原书插图）**`。
- 不允许出现跳跃（如 1→3）、重复编号、或把概念图误标成“原书局部截图”。
- 章节收尾核对：图注编号应为 `图N-1 .. 图N-K`（K=图片总数），连续无缺。

## 三、正文规则

- 层级：用 `# 章名`、`## 小节`、`### 子节`；关键结论用加粗/表格，公式用文本行。
- **上标/特殊字符**：图片内不要用 Unicode 上标（⁹ ³ ⁰ ⁻¹⁷ 会缺字成“口”），用“小字号数字+上移”；MD 正文可用 `10^-17` 或说明文字，避免缺字。
- 章节结尾要有“小结”；`00-学习目录.md` 更新为“已完成”，并链接本 md 与插图目录。

## 四、检查清单（每条必查）

1. 图片引用全部存在（无 missing 路径）。
2. 图注连续编号；每图恰有一条；原书号/概念标签正确。
3. 原书裁图不越界、不夹正文、无整页、无原书图注。
4. 概念图无越界、无重叠、无明显留白（顶部标题块不压边框）。
5. 正文无占位符 / “TBD” / 未替换的临时字段。
6. 编号与图片顺序一致；插图目录与命名规范。
7. 运行校验脚本后再交付。

## 五、可复用脚本

- `renumber_captions.py`：把图注统一重编号（连续 + 括号保留原书图号）。
- `audit_crop_margins.py`：检查裁图边缘是否贴边/被切。
- `audit_concepts.py` / `audit_ch5_v2.py`：检查概念图越界、重叠、留白。

## 六、原书裁图补充规范（v2）

1. **矢量图必须包含图内文字标签**：很多架构图/原理图的左右两侧电压、字线、状态标签是“文字”，不在图形对象范围内；按图形边界裁剪会切掉标签。此类图要加“显式裁切框”，把标签全部包进来（并避开正文）。
2. **示例**：
   - 图5-9 写入操作原理（V_PASS / V_PROG / V_INH / WL0–WL2 / SSL / GSL / BL0–BL3）；
   - 图5-18 读干扰原理；
   - 图4-8 Bravera SC5 主控架构（PCIe 5.0 / 1×4 / 2×2 / NAND 8CH/8CE / 16CH/8CE / 4CE,72 位宽接口）。
3. **默认策略**：先按“图形区域”裁剪（避免夹入正文）；若图内文字标签贴到左右/上下边缘，则切回“显式坐标框”覆盖。
4. **边缘扫描**：每章裁图后用 `audit_crop_margins.py` 检查；左右边缘出现“半截文字”（如 `V_PASS` 只剩 `PASS`、`WL0` 只剩 `WL(`）即为被切，必须返工。
5. **整跨页图**：内容本身延伸到版心边缘、四周无留白属正常；但若某侧出现“文字半截”，判定为裁切不完整，需扩大/显式框。

# 示意图生成与检查规范（SSD 学习）

> 适用范围：**自绘的概念示意图**（不包含原书裁图）。每张图生成后都要按下面的“检查清单”逐项自检，全部通过后再交付。

## 一、生成要求

- **风格统一**：圆角卡片、微软雅黑；主题色 蓝 `#2b6cb0`、绿 `#2f855a`、橙 `#b7791f`、灰 `#4a5568`；同类型卡片等高、左→右/上→下排列。
- **文字布局**：居中文字用 `mmtext`（anchor=“mm”，不要传 None）、左对齐用 `ltext`；会换行的说明用 `wrap()` 按测量宽度自动换行，绝不能写好长一句硬塞。
- **箭头**：统一为“粗轴线 + 圆头起点 + 实心三角头”；箭头与相邻框图留 8~12px；方向由语义决定（写→右/读→左）；颜色保持各图逻辑（写=蓝、读=绿、通用=灰）。
- **上标数字**：不要用 Unicode 上标（⁹ ³ ⁰ ⁻¹⁷ 会缺字成“口”），用“小字号数字 + 正偏移”实现。
- **图注**：图中不要画“原书图注”；章节正文 MD 里每张图下加 `**标题（概念示意图，非原书插图）**`。
- **文件**：命名 `concept_<主题>.png`，放 `第N章_插图/`；MD 用相对路径 `第N章_插图/concept_xxx.png`；禁止用生成式图片冒充原书图。

## 二、检查清单（每条必查）

1. **文字不越界**：对每张卡片/面板，扫描非白像素的 x 范围，必须落在 box 边界内（±1px）。
2. **元素不重叠**：检查“标签→框、说明区→单元、标题栏→内容、相邻框”之间空白带无像素；文字说明区与电压/标签至少留 30px。
3. **留白合理**：主要内容底部到卡片底边 < 25%；若空白大，就压缩卡片高度或上移/补内容，不要留一大块空白。
4. **排列合理**：按“主机→控制器→NAND / 问题→保障 / 类型→特性”的阅读顺序；同等级内容等高对齐；说明区、公式区、图例分区清楚。
5. **箭头正确**：方向、颜色、圆头+三角样式无误；不压框图。
6. **可读性**：字号不小于 16px（正文观点尽量 18~22px）；中文换行正常，不出现单字孤行。
7. **校验通过**：运行 `audit_concepts.py`（或等价像素扫描），输出内容均在框内、无重叠、无大留白。
8. **交付确认**：每张新图生成后先打开右侧预览，再入库 `ssd学习/第N章_插图/`。

## 三、快速自检命令

在 Codex 工作区运行：

```bash
python audit_concepts.py
```

审计会输出：每张图各面板的“内容 x 范围是否越界”“内容底部空白百分比”，并单独检测容易重叠的关键空白带。

## 四、补充规范（v2，2026-09 反馈修订）

1. **顶部标题块样式统一**：所有面板/卡片顶部标题块使用“圆角内嵌 + 白色描边留白”样式（即标题块四周留出白色间隙，不与面板边框贴死）。参考标准：顶部标题块 inset 约 14~16px，白描边宽 4~5px。
2. **结论/底部说明条要够大**：底部结论框高度建议 ≥120px、字号 ≥22px，不要做成细长条；与主体内容之间留 30~60px 即可。
3. **有空白就压缩**：卡片/面板底部若有大块空白，优先“压缩面板高度 / 上移内容”，不要留大段没内容的区域；主要卡片底部空白建议 <10~15%。
4. **长文字不许超框**：层级框/卡片标题用短措辞或加宽框体，扫描确认文字 x 范围都在框内（±1px）；多用 `wrap()` 自动换行。
5. **内容区域与结论分区**：主体内容区、记忆/结论区、图例区要分区清楚，避免大段空白“悬空”。
6. **整改后复检**：涉及“留白/重叠/越界”的改动，改完必须重新运行 `audit_concepts.py`（或 `audit_ch5_v2.py`），确认：内容在框内、无重叠、空白百分比达标后再交付。

## 五、补充规范（v2.1）

1. **顶部边框必须完整**：标题块必须整体内嵌在面板内（上沿距面板上边 ≥12px），不能覆盖或擦掉面板的上边框线；检查时用像素确认面板上边框有连续线条。
2. **不要留空占位行**：没有实际内容的行/省略号/横线不要保留；结论、要点必须有真实文字，并保证足够大（结论框 ≥120px 高、字号 ≥22px）。

## 六、补充规范（v2.2）

1. **文字不能顶到框底**：每张卡片内的最后一行文字，与卡片底边至少留 **40px 余量**；不允许文字贴着/压到框图边缘。
2. **如何保证**：面板内容偏多时，优先“减少要点数量 / 缩小行距 / 上移内容起点”；内容偏少时，压缩面板高度或补内容，兼顾“底边余量”与“不留下大片空白”。
3. **检查方式**：用像素扫描统计“最后一行文字的 y 与面板底边 y 之差”，要求 ≥40px；同时面板内空白比例保持 ≤15%～20%。
